API Reference

POST

/v1/tenants

Creates a new tenant securely isolated within the QuotaForge environment. This endpoint provisions initial routing rules, default rate limits, and an isolated configuration space.

Authentication

key Bearer Token required. Requires tenant:write scope.

Body Parameters

Parameter Description
name required
string 		The unique identifier for the tenant. Must be alphanumeric, lowercase, and cannot contain spaces. Max 64 characters.
tier
string 		The subscription tier defining default quotas. Valid options are free, pro, or enterprise. Defaults to free.
metadata
object 		Up to 20 key-value pairs for attaching custom data to the tenant object. Keys must be strings under 40 characters.

Returns

Returns a tenant object if the creation succeeds.

201 Created
400 Bad Request
409 Conflict
